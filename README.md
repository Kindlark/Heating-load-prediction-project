# project-liceum


Название: прогноз тепловой нагрузки здания по архитектурным параметрам.

Цель: предсказывать Heating Load по 8 входным параметрам.

Датасет: UCI Energy Efficiency — 768 наблюдений.

Модели: Linear Regression, Ridge, Lasso, XGBoost или LightGBM.

Метрики: R² и MAPE.

Дополнительная задача: поиск архитектурных конфигураций с помощью Grid Search или Random Search.
